# Malaria in Pregnancy and Child Socio-Emotional Development

This repository contains all the data management and statistical analysis scripts used in the paper:

**“The effects of malaria in pregnancy on children’s socio-emotional development at 6 years of age in Benin: A prospective mother–child cohort”**

## Overview

The scripts in this repository were used to prepare, clean, and analyze data from a longitudinal cohort study investigating the impact of malaria exposure during pregnancy on socio-emotional and cognitive development in children at age 6.

Analyses include:
- Data preparation and variable creation
- Descriptive statistics and population comparisons
- Linear regression models (unadjusted and adjusted)
- Pooled analyses using multiply imputed datasets
- Subgroup analyses (e.g., TOVA ADHD assessments)
- Sensitivity analyses
- Attrition analyses
